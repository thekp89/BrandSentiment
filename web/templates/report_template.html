Metodología KRI (Key Risk Indicator): El sistema evalúa el nivel de toxicidad y riesgo SEO de cada enlace entrante en una escala de 0 a 100. La puntuación ignora dominios de listas blancas y suma puntos en base a factores combinados:
  • Disponibilidad: Enlaces rotos o con códigos de error HTTP 4xx/5xx (+20 pts).
  • Contexto Tóxico: Presencia de palabras clave maliciosas (ej. apuestas, contenido adulto, fraudes) en la página o texto circundante (+15 pts por coincidencia).
  • Reputación de Dominio: TLDs genéricos o redes frecuentemente usadas para spam (ej. .xyz, .top, .online) (+10 pts).
Escala de Severidad: Tóxico (≥ 70 pts), Sospechoso (30-69 pts), Seguro (0-29 pts).
